# Cryptocurrency Price Tracker

## About the Project
The Cryptocurrency Price Tracker is a Python-based project that collects cryptocurrency market data and stores it for tracking price changes. It helps users view cryptocurrency prices and understand their 24-hour price movements.

## Features
- Tracks cryptocurrency market prices.
- Displays price changes and market information.
- Collects data using Python.
- Stores cryptocurrency data in CSV format.
- Supports exporting CSV data to Excel.
- Includes HTML pages for displaying cryptocurrency information.

## Technologies Used
- **Python** – Data collection and processing
- **HTML** – Web page structure
- **CSS** – Web page styling
- **JavaScript** – Web page interactions
- **CSV** – Data storage
- **Excel** – Data analysis and storage

## Project Files
- `app.py` – Python application
- `crypto_tracker.py` – Cryptocurrency tracking script
- `csv_to_excel.py` – Converts CSV data into Excel format
- `crypto_prices.csv` – Stores cryptocurrency data in CSV format
- `crypto_prices.xlsx` – Excel file containing cryptocurrency data
- `index.html` – Web page
- `live_crypto.html` – Cryptocurrency display page
